# webhtv-plugin-douban

WebHTV 的豆瓣短评面板插件。在详情页或播放页点一下「豆瓣」chip，就能看到当前片子在豆瓣的总评分、打分分布和最新短评——不用跳出 App 去翻豆瓣。

## 显示什么

- **总评分**（豆瓣的 10 分制）与星级视觉锚点
- **评价人数**、**短评总数**
- **1–5 星打分比例**：横向条形 + 百分比，5 星在最上、1 星在最下
- **短评列表**：用户名、时间、有用数、该用户打的分、正文

短评匿名只能看前 150 条（豆瓣限制），这是接口的上限，不是插件的取舍。插件一次调用会把数据全部取回，滚动到底自动揭开更多，不额外发请求。

## 目录结构

```
douban/
  manifest.json   插件清单：id、权限、槽位、参数
  douban.js       全部逻辑（ES5 单文件）
```

两个文件就是全部。**没有构建步骤、没有依赖、不需要编译。**

## 安装

App 的插件导入入口只接受**目录**，不认 `.zip` 文件——直接选中一个压缩包会提示「插件路径不是目录」。所以：

1. 在本仓库点 **Code → Download ZIP**
2. **解压**下载到的压缩包
3. 打开 WebHTV，进入「设置 → 插件管理」
4. 点「导入插件」，选中解压出来的 **`douban` 目录**（这个目录里直接就有 `manifest.json` 和 `douban.js`）
5. 导入成功后插件默认启用；点「重新装载」或重进详情页即可看到「豆瓣」chip

导入后插件文件会被复制到 App 私有目录，原解压地点可以删掉。更新版本时重复以上步骤覆盖安装即可。

## 权限与用途

| 权限 | 用途 |
| --- | --- |
| `plugin.events` | 订阅 `ui.contentShown`，在内容显示时刷新上下文 |
| `plugin.data.episode` | 取当前片名与类型，用于搜索豆瓣条目 |
| `net.request` | 请求 `m.douban.com` 的 rexxar 接口 |
| `ui.panel` | 在详情页与播放页挂「豆瓣」chip，并打开侧滑面板 |

想拦住插件的联网行为，靠的是这些权限声明，而不是 URL 白名单——宿主不提供域名过滤。本插件发出的每一次请求都会进宿主审计日志。

## 依赖的豆瓣接口

以下都是豆瓣 **非公开** 的 rexxar 接口，不属于对外承诺的 API，随时可能改动、失效或触发风控：

| 接口 | 用途 |
| --- | --- |
| `/rexxar/api/v2/search/subjects?q=` | 用片名搜条目，取 subject id |
| `/rexxar/api/v2/movie/<id>` | 详情：总评分、评价人数、短评总数、是否剧集 |
| `/rexxar/api/v2/movie/<id>/rating` | 打分分布：`stats` 为长度 5 的数组，下标 0→1 星 … 4→5 星 |
| `/rexxar/api/v2/movie/<id>/interests` | 短评列表，单页最多 50 条 |

剧集条目不需要特殊处理：`/movie/<tvId>/rating` 会 302 到 `/tv/<tvId>/rating`，宿主跟随重定向。

接口拿不到打分分布时，面板会**安静地少掉那一块**，其余内容照常显示——不会留空条或占位符。

## 卸载

在 App 的「插件管理」里删除该插件即可，会连文件一起清掉。
